The preview is generated, never hand-edited: `tools/build_next.py` reads the live bundle, applies asserted patches, appends `tools/duo.css` to the main stylesheet, and writes `next/app.<hash>.js` + `next/index.html` (fetches `../data.json`, so same data; same origin, so the same saved sets/notes). The script uses absolute `/home/claude/...` paths; fix them if the workspace differs. To promote the preview to live: point `SRC`/output at the repo root, drop the `../data.json` and `../icon.png` rewrites, rehash, update root `index.html`.
  - New localStorage keys (the old `cr-wide` is no longer read in the preview): `cr-layout` = auto|phone|wide|split, `cr-pin` = brief|days|trends|plan, `cr-lg` = 0|1.
  - Hook `fy()` returns `{pref,setPref,pin,setPin,lg,setLg,mode}`; `mode` is phone (<561 px or forced), wide, or split (auto picks split at ≥740 px, wide at 561–739). Root classes: `.wide` (one wide page, right rail, as before), `.split` (two pages: `.pane-side` = pinned page, sticky with its own scroll; `.pane-main` = active tab), `.solo` (two-page mode but the pinned page's own tab is selected, so it shows alone in two columns), `.lg` (Liquid Glass).
  - In two-page mode the tab bar sits at the bottom of the right half and controls the right page; the pinned tab shows a mint dot. The pin chip (shown in split) pins the current page left and swaps the old pinned page to the right. Entering split while on the pinned page auto-switches to the last other page.
  - `hy` is now the layout/appearance menu (chip in `.ctrls`): layout segmented control, pinned page, Liquid Glass switch.
  - Liquid Glass CSS must use the prefix `html body div.cr-root.lg[data-theme]` because the dark theme has `!important` rules at `html body div.cr-root[data-theme="dark"]` specificity (they also hide `.cr-glow` and `.glass::after`). The old "glass" theme (third theme button) is unchanged.
  - Viewport sizes used for the Duo (third-party estimates, not measured on his device): folded 466×678, open 626×890 upright / 890×626 flat. Testing: `node` + Playwright at those sizes; seed `cr-layout`/`cr-lg`/`cr-theme` via addInitScript.
